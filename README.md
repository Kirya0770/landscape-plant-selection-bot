# Landscape Plant Selection Bot 🌿

Телеграм-бот для автоматизированного подбора растений в ландшафтном проектировании на основе почвенных, световых и климатических условий участка. Разработан по заказу ландшафтных специалистов.

---

## Основной функционал

- **Многокритериальная фильтрация:** точечный и множественный отбор по 5 ключевым параметрам: кислотность почвы (pH), влажность, требования к дренажу, инсоляция (свет) и климатическая устойчивость.
- **In-Memory кэширование датасета:** база данных Excel (270+ записей) считывается и индексируется один раз при инициализации бота, предотвращая блокирующий ввод-вывод при пользовательских запросах.
- **Векторизованный поиск:** фильтрация через структуры pandas для мгновенной отдачи результатов.
- **Интерактивная пагинация:** компактная постраничная выдача (по 5 карточек) без риска спама и превышения лимитов Telegram API (FloodWait).
- **Горячее обновление данных:** админ-команда /reload перечитывает таблицу plants.xlsx без перезапуска сервиса.
- **Отказоустойчивая верстка:** рендеринг ответов в формате HTML со строгим экранированием специальных символов.

---

## Стек технологий

- **Язык:** Python 3.10+
- **Фреймворк:** aiogram 3.x (Asyncio, FSM, State storage)
- **Обработка данных:** pandas, openpyxl
- **Конфигурация:** python-dotenv
